Kairos

when2meet-style scheduling polls — self-hostable, reverse-proxy-auth friendly, agent-first.

Try it in your browser → GitHub

The playground runs the actual Python server in your browser (Pyodide/WASM + SQLite). Nothing is uploaded; reload = fresh instance.

Run it for real

uvx --from git+https://github.com/gerchowl/kairos kairos
# → http://127.0.0.1:8003  (SQLite, demo auth)

Why

  • Full-day & time-slot polls, drag grids, heatmaps, public share links
  • Required/optional invitees → convergence light (collecting → ready/partial/blocked)
  • Idempotent smart reminders + per-participant contact audit trail
  • Decide → .ics download + “email everyone” with the file attached
  • Bring your own SSO: trusts identity headers from Shibboleth, oauth2-proxy, Authelia, Cloudflare Access…
  • Agents: Bearer API, OpenAPI, /llms.txt, MCP server
